3. **QA/UAT** runs the Test Plan (04); owner signs off below before go-live.

## Honest-positioning guardrail (read before writing any copy)

The owner is a public library director who has written and won grants firsthand (several, **≤ $5,000 each, ~50% success rate**, via community foundations, humanities councils, and state programs) but is **not yet certified** and has so far written grants only for her own library. All copy must rely on real, modest experience and trustworthiness **without overclaiming**. Certification and external wins are deferred and added later.

## Open questions to confirm before/at build

These were not fully specified in discovery — confirm with the owner:

1. **Single-page vs. light 3-page** — default is single-page; confirm preference.
2. **Platform** — Squarespace recommended; confirm final choice (affects form tooling).
3. **Auto-reply SLA wording** — "in touch within X business days" → what is X?
4. **Footer contact details** — exact email address and phone number to publish.
5. **Headshot** — available by Day 2, or launch without and add later?
6. **Optional credibility line** — include the ~50% success-rate line at launch, or hold?
7. **Organization type field** — free-text or fixed dropdown (arts / education / women's services / community / other)?
8. **Analytics** — install basic analytics at launch (privacy-minimal), or not?
